# Halbestunde 与 MuseScore 操作要点

按当前界面而非固定坐标或旧版本按钮索引操作。菜单、导出格式和平台支持会随版本改变。软件未安装时不假定已有授权、账号或订阅；获取软件或上传原谱仍遵守当前任务的权限。

## Halbestunde → MusicXML

1. 用当前环境提供的电脑控制接口定位 Halbestunde，确认窗口身份与是否有未保存项目。
2. 在界面中导入指定 PDF，核实选中文件名、页数与缩略图。只在应用要求时提供其必要的文件访问许可。
3. 完成识别，查看首尾页和异常页，导出实际可用的 MusicXML 文件。记录导出路径，检查文件存在、非空且能解析。
4. 保留此原始 OMR 输出，在副本上修订。转换质量与“识别完成”提示是两回事。

### 授权状态异常

若显示 `Please authorize via Muse Hub`，先确认 Muse Hub 中的登录／产品授权状态，再通过其当前提供的打开入口返回应用。用户完成登录、MFA 或修复后，从新状态继续，不重复整轮调查。

授权仍失效时，最多做一次有明确依据的状态刷新或安全重开。重开前确认当前工作已保存，或用户已明确同意舍弃。没有状态变化时不要循环打开、退出或等待；交代具体阻塞，让用户完成必需的账户操作。技能不能绕过认证或审批拒绝。

## 修订稿 → MSCZ → PDF

1. 在 MuseScore 打开修订的 MusicXML／MSCX。原生稿同时保留正确样式，见 [原生文件注意事项](native-mscz.md)。即使自动识别了标题，也要核实文件名、声部与小节；同一应用可能有多个进程或窗口。
2. 对照源谱核对声部映射。OMR 可能把一个声部拆成多个 part，甚至把末页并入新 part。不要把“parts 数量”和“staves 数量”混为一谈；钢琴等单个 part 可以有多条谱表。
3. 另存为用户工作目录中的独立 MSCZ；若出现本地／云端选项，此转换任务通常选本地。云端发布不是转换的默认步骤。
4. 确认文件已写入，关闭已保存的目标稿，从首页最近文件或 Open 打开其确切路径，核实标题和保存状态。读取 ZIP 容器指定的主 MSCX，不要因包含分谱而随便取第一个 `.mscx`；按所选校验深度回读，默认精校须重新对照独立源谱记录逐项验证内容。
5. 从当前界面的 File → Export 选择主总谱和 PDF，确认输出路径、文件及页数。不猜未验证的导出快捷键，以免快捷键被当作音符输入。分谱和音频只在请求范围内导出。
6. 把 PDF 渲染为图像检查。可用 Poppler（`pdfinfo`、`pdftoppm`），或可用的等价 PDF 渲染器。原 PDF 与输出 PDF 的页数可以因合理排版不同；核验全部音乐内容，而不是强求同页数。

未要求 GUI 时，可使用当前环境允许的官方 MuseScore CLI 做文件导入导出，但 CLI 不提供 PDF 光学识别能力，也不免除重新读取和渲染验证。若用户限定 GUI 或审批拒绝另一实现方式，不用其他进程、脚本或命令间接绕过。

## 多窗口与控制接口问题

- 每次选择或切换后，重新读取窗口标题、文件路径和保存状态，确认是目标稿。不要用缓存的 AX 元素编号作用于新窗口。
- macOS 下，不同乐谱可能属于不同 MuseScore 进程；接口也可能绑定旧窗口。只使用接口实际支持的窗口发现与选择能力，不臆造 `listWindows` 或窗口切换 API。
- 常见安全恢复路径：在 Finder／资源管理器中选中确切目标文件并打开；重新绑定 MuseScore；必要时先把本任务的导入临时稿另存，再关闭已保存的临时稿及空首页窗口，随后重新绑定目标窗口。
- 未保存的无关作品由用户处理，或在明确授权下保存到合适位置。不要盲目退出全部实例、强杀应用或清理恢复数据。
- 若界面变更提示阻止动作，重新读取状态；索引动作失败时可根据最新截图操作。每次采用实质不同的恢复策略；两次没有新证据的尝试后停止重复动作，保留已完成产物并报告所需的最小用户配合。

### 自动保存恢复仅作例外

只有正常保存受阻，且能在授权范围内定位自动保存文件时才考虑恢复。先只读核实曲名、声部、小节及最近导入内容，再将匹配文件复制到任务目录；不要改写或清空应用恢复目录。

自动保存路径因平台与版本而异，不能硬编码别人电脑的路径。恢复副本必须重新用 MuseScore 打开并导出渲染，不能仅因 ZIP 可解析就交付为精校完成。无法确认属于本任务时停止，不猜测。

## 时间与成功判定

等待识别／导出时采用可观察的状态检查；较长等待期间持续说明进度。不要因程序进程存在、菜单响应、日志显示“save”或自动保存文件存在就声称完成。最终证据是确切的交付文件、重新打开结果、保存内容核验和对应渲染。
